# Denominate data

"Denominates" or "scales" variables by other variables. Typically this
is done by dividing extensive variables such as GDP by a scaling
variable such as population, to give an intensive variable (GDP per
capita).

## Usage

``` r
Denominate(x, ...)
```

## Arguments

- x:

  Object to be denominated

- ...:

  arguments passed to or from other methods

## Value

See individual method documentation

## Details

See documentation for individual methods:

- [`Denominate.data.frame()`](https://bluefoxr.github.io/COINr/reference/Denominate.data.frame.md)

- [`Denominate.coin()`](https://bluefoxr.github.io/COINr/reference/Denominate.coin.md)

- [`Denominate.purse()`](https://bluefoxr.github.io/COINr/reference/Denominate.purse.md).

This function replaces the now-defunct `denominate()` from COINr \<
v1.0.
