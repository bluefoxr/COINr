# ASEM raw indicator data

A data set containing raw values of indicators for 51 countries, groups
and denominators. See the ASEM Portal for further information and
detailed description of each indicator. See also
[`vignette("coins")`](https://bluefoxr.github.io/COINr/articles/coins.md)
for the format of this data.

## Usage

``` r
ASEM_iData
```

## Format

A data frame with 51 rows and 60 variables.

## Source

<https://composite-indicators.jrc.ec.europa.eu/asem-sustainable-connectivity/repository>

## Details

This data set is in the new v1.0 format.
