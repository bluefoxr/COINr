# ASEM COIN (COINr \< v1.0)

This is an "old format" "COIN" object which is stored for testing
purposes. It is generated using the COINr6 package (only available on
GitHub) using `COINr6::build_ASEM()`

## Usage

``` r
ASEM_COIN
```

## Format

A "COIN" class object
