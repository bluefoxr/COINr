# Statistics of columns/indicators

Generic function for reports various statistics from a data frame or
coin. See method documentation:

## Usage

``` r
get_stats(x, ...)
```

## Arguments

- x:

  Object (data frame or coin)

- ...:

  Further arguments to be passed to methods.

## Value

A data frame of statistics for each column

## Details

- [`get_stats.data.frame()`](https://bluefoxr.github.io/COINr/reference/get_stats.data.frame.md)

- [`get_stats.coin()`](https://bluefoxr.github.io/COINr/reference/get_stats.coin.md)

See also
[`vignette("analysis")`](https://bluefoxr.github.io/COINr/articles/analysis.md).

This function replaces the now-defunct `getStats()` from COINr \< v1.0.
